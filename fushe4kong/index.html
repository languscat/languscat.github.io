基础操作指南

1. 开启控制台

在游戏画面中，按下键盘上的 [ 键（通常位于左上角数字键1下方）打开控制台。再次按下即可关闭。

~ 或 [

2. 选中目标

开启控制台后，点击游戏内的角色、物品或建筑即可选中。选中后会出现绿色数字编号。

点击目标物体

3. 常用命令

输入指令后按回车执行。最常用的包括无敌模式、穿墙模式等。

tgm (开启无敌与隐身)
tm (关闭HUD界面)

常见问题 (FAQ)

控制台打不开怎么办？
请确保你没有处于全屏游戏模式。如果是全屏，请先按 Alt+Tab 切换到桌面，然后再按 [ 键。部分游戏版本可能需要在游戏设置中开启控制台支持。
代码输入后没有反应？
请检查是否正确选中了目标物体。如果是对玩家使用，请确保指令前缀正确（如 player.），且数量为正整数。部分代码可能需要重启游戏才能生效。
如何关闭无敌模式？
在控制台输入 tmm 1 开启，输入 tmm 0 关闭。输入 tgm 则是切换开关。
